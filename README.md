## 🚀 Projeto em Destaque

### [PsiAdmin - Painel de Gestão para Saúde](https://sistema-agendamento-kappa.vercel.app/)
Um sistema administrativo completo focado em experiência do usuário (UX) para profissionais de saúde.
- **O que faz:** Agenda dinâmica com filtros inteligentes, navegação SPA (Single Page Application) e gestão de pacientes.
- **Diferencial Técnico:** Uso avançado de hooks do React (`useState`, `useEffect`) e estilização responsiva com Tailwind CSS.
- **Destaque:** Sistema de categorias visuais para Sessões, Pausas e Lembretes, integrando agilidade e design limpo.
